# Визуальный профиль университета

AI-сервис, который по названию университета находит, проверяет и категоризирует фотографии кампуса, общежитий, аудиторий, библиотек и города — с указанием источника и честной оценкой достоверности.

## Задача
LOCUS Startup Hackathon 2026, Кейс 01.

## Стек
- Backend: Python, FastAPI
- Поиск фото: Serper.dev (Google Images API)
- AI-верификация и описание: Google Gemini (gemini-flash-lite-latest)
- Удаление дублей: perceptual hashing (imagehash)
- Frontend: HTML/CSS/JavaScript
- Хостинг: Render.com

## Как это работает
1. Пользователь вводит название вуза
2. Сервис параллельно ищет фото по категориям: campus, dormitory, library, classroom, city
3. Каждое фото скачивается и анализируется AI-моделью на предмет соответствия категории и вузу, с оценкой уверенности от 0 до 100%
4. Дубли удаляются через сравнение перцептивных хэшей
5. Генерируется краткое AI-описание университета
6. Результат отдаётся с источником, названием фото и честной оценкой достоверности

## Запуск локально
1. Установить зависимости: pip install -r requirements.txt
2. Запустить сервер: python -m uvicorn main:app --reload
3. Открыть в браузере: http://127.0.0.1:8000

## Переменные окружения
Файл .env должен содержать две строки:
SERPER_API_KEY
GEMINI_API_KEY

## Ограничения
- Категории пока: campus, dormitory, library, classroom, city — «спорт» и «лаборатории» из расширенного списка кейса в разработке
- Дата публикации фото не отображается — источники не предоставляют эту информацию через открытые API
- Бесплатный тариф Gemini и Render ограничивает скорость и параллелизм обработки
- Первый запрос после простоя на Render может занимать до 50 секунд
- Точность верификации выше для широко известных университетов
